Before the first run
  • Connect the microphone to the selected input and the speaker to the selected output.
  • Use one interface for input and output. Grant microphone access to the local launcher if your operating system asks.
  • Use phantom power only if your microphone requires it. Keep input monitoring off.
  • Set gain so the microphone signal is audible above background without clipping. Avoid changing gains or geometry between timing and stimulus runs.
  • A 27 kHz digital tone does not establish that the speaker or microphone reproduces 27 kHz. Check the acoustic hardware response separately.

What this measurement means

The simple method compares the generated chirp with the recorded microphone signal. It includes audio I/O latency and is useful for checking the whole playback–recording path.

The electrical method compares the microphone with a copy of the output recorded on another input of the same interface. It removes shared playback timing from that comparison. Speaker and microphone response, acoustic travel, and differences between the two analog paths remain.

The chirp is a timing probe, separate from the SONIC stimulus. A rejected run does not produce a calibrated delay. This tool does not measure neural latency or validate an animal stimulus protocol.

Keep the same routing and geometry for your stimulus run.

Source, adaptations & limits

Source: SONIC bioRxiv v1, experiment E14. The recipe uses 14 frequencies, 10 ms tone pips, and 2 ms onset/offset ramps in a continuous randomized sequence. Published blocks contained 8,000–15,000 pips.

This implementation: balanced seeded randomization and raised-cosine ramps. The default of 600 pips per frequency gives a local 8,400-pip, 84-second sequence; it is not a published per-frequency count. The original order, ramp function, and calibrated acoustic level are unavailable, so these waveforms should not be described as the original SONIC audio.

The published experiment used awake, alert sheep. The planned Rice study uses sedated sheep; timing windows and performance under sedation remain unverified. This app is a bench stimulus and timing tool, not an animal-ready protocol or a claim of reproduced neural results.
