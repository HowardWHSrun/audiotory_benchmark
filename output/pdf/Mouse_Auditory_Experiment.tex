{\LARGE\bfseries Mouse auditory experiment}\par
{\color{muted}A first plan \hfill October 8, 2026}\par

We want to play short tones to a mouse and record how its brain responds, using SONIC as a starting point.

\topic{1. Choose the sounds}
\begin{itemize}
\item Choose the frequency, duration, loudness, and gap between tones.
\item Add short fades at both ends to avoid clicks.
\item Save the sequence and settings so we can identify every tone.
\item SONIC used 10 ms tones with 2 ms fades in awake sheep. Our mouse settings and awake versus anesthetized state remain open.
\end{itemize}

\topic{2. Set up the speaker}
\begin{itemize}
\item Check what audio equipment the lab already has.
\item Consider the TDT MF1 speaker and SA1 amplifier used in SONIC.
\item Keep the speaker in a fixed position.
\item Measure each tone's loudness with a suitable calibrated microphone at the ear position.
\end{itemize}

\topic{3. Keep everything on one timeline}
\begin{itemize}
\item Schedule each tone with an electrical timing pulse.
\item Record the pulse alongside the neural signals.
\item Synchronize the microphone recording to check when the sound actually reaches the ear.
\item If we add behavior video, synchronize its frame times too.
\end{itemize}

\topic{Start here}
\begin{itemize}
\item Identify the neural recorder and available audio equipment.
\item Test the sound, timing, and unwanted electrical pickup on the bench.
\item Once those checks work, use the team's mouse protocol to start with tones separated by silence.
\end{itemize}
